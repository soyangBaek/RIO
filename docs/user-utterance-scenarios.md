# User Utterance Scenarios

사용자 관점에서 "이렇게 말하면 RIO가 이렇게 반응한다"를 한눈에 보는 카탈로그입니다.
내부 구현(상태, 이벤트, 페이로드)은 [utterance-scenarios.md](./utterance-scenarios.md)를 참고하세요.

> 공통: 말을 시작하면 **좌하단에 점 3개 애니메이션**이 뜨고 짧은 **"듣고 있어요" 효과음**이 재생됩니다. 말이 끝나면 RIO가 해석해서 아래 동작 중 하나로 이어집니다.

> **단일 발화 원칙**: 각 명령마다 공식 발화는 **하나**입니다. 아래 표에 적힌
> 문장 그대로 말해야 인식됩니다. 유사 표현/영어/약어는 지원하지 않습니다.

---

## 1. 집안 기기 제어

### 에어컨

| 말 | RIO 반응 |
|---|---|
| "에어컨 켜줘" | 에어컨 켜짐 → 성공 사운드, 기쁜 표정 |
| "에어컨 꺼줘" | 에어컨 꺼짐 → 성공 사운드, 기쁜 표정 |

### 난방

| 말 | RIO 반응 |
|---|---|
| "난방 켜줘" | 히터 켜짐 |
| "난방 꺼줘" | 히터 꺼짐 |

### 조명

| 말 | RIO 반응 |
|---|---|
| "거실 등 켜줘" | 거실 조명 켜짐 |
| "거실 등 꺼줘" | 거실 조명 꺼짐 |
| "간접등 켜줘" | 간접등 켜짐 |
| "간접등 꺼줘" | 간접등 꺼짐 |

### TV / 컴퓨터

| 말 | RIO 반응 |
|---|---|
| "티비 켜줘" | TV 켜짐 |
| "티비 꺼줘" | TV 꺼짐 |
| "컴퓨터 켜줘" | 컴퓨터 켜짐 |
| "컴퓨터 꺼줘" | 컴퓨터 꺼짐 |

### 청소기 / 공기청정기

| 말 | RIO 반응 |
|---|---|
| "청소기 돌려줘" | 로봇 청소기 시작 |
| "청소기 정지" | 로봇 청소기 정지 |
| "공기청정기 켜줘" | 공기청정기 켜짐 |
| "공기청정기 꺼줘" | 공기청정기 꺼짐 |

### 음악

| 말 | RIO 반응 |
|---|---|
| "음악 틀어줘" | 음악 재생 시작 |
| "음악 꺼줘" | 음악 정지 |

### 전체 제어

| 말 | RIO 반응 |
|---|---|
| "다 꺼줘" | **모든 기기가 한 번에 꺼짐** → 성공 사운드 |

## 2. 카메라 / 사진

| 말 | RIO 반응 |
|---|---|
| "사진 찍어줘" | 얼굴 화면에 카메라 프레임 등장 → **3·2·1 카운트다운** → 셔터음과 함께 촬영 → "Photo saved" 안내 |
| (촬영 직전) "취소" | 취소되지 않고 촬영 완료 (카운트다운은 이미 진행 중) |

---

## 3. 타이머

| 말 | RIO 반응 |
|---|---|
| "5분 뒤에 알려줘" | 5분 타이머 등록 → 등록 사운드 재생 |
| "30초 뒤에 알려줘" | 30초 타이머 등록 |
| (타이머 만료 시) — | **알림 화면 + 알람 사운드 + "타이머 시간 됐어요"** |
| (알림 중) "확인" | 알림 해제 |

> 타이머는 "**숫자 + 분/초 + 뒤에 알려줘**" 형식만 인식합니다. 시간 표현이
> 빠지면 못 알아들은 표정으로 반응합니다.

---

## 4. 날씨

| 말 | RIO 반응 |
|---|---|
| "날씨 알려줘" | 현재 날씨 조회 → "지금 날씨는 OO, 기온 XX도예요" 안내 |
| (조회 실패 시) — | 못 알아들은 표정 + "날씨를 가져오지 못했어요" |

## 5. 놀이 모드

### 댄스

| 말 | RIO 반응 |
|---|---|
| "춤춰줘" | **댄스 음악 10초간 재생**, 얼굴 집중 표정 |
| (댄스 중) "취소" | 음악 멈추고 대기 상태로 복귀 |

### 게임 모드

| 말 | RIO 반응 |
|---|---|
| "게임 모드" | 게임용 UI로 전환 → 전환 사운드, "Entering game mode" |
| (게임 중) "취소" | 일반 모드로 복귀 |

---

## 6. 시스템 명령

| 말 | 상황 | RIO 반응 |
|---|---|---|
| "취소" | 듣고 있을 때 | 조용히 대기 상태로 복귀 |
| "취소" | 댄스/게임 중 | 해당 모드 종료 |
| "확인" | 타이머 알림 중 | 알림 해제 |

---

## 7. 음성 인식 실패 케이스

| 상황 | RIO 반응 |
|---|---|
| 발음이 불분명하거나 인식 실패 | **못 알아들은 표정** (confused), 대기 상태로 복귀 |
| 공식 발화가 아닌 문장 | 동일하게 못 알아들은 표정 |
| 목소리가 너무 작아서 VAD가 트리거되지 않음 | 아무 반응 없음 (RIO는 말을 못 들은 상태) |

---

## 8. 특수 상황

| 상황 | RIO 반응 |
|---|---|
| RIO가 사용자를 못 본 상태에서 갑자기 말을 걸 때 | **화들짝 놀라는 표정**(startled) 후 듣기 시작 |
| 오랜만에 다시 얼굴을 비추고 말을 걸 때 | **반기는 표정**(welcome) 후 듣기 시작 |
| 스마트홈 제어가 실행되는 도중에 다음 명령을 걺 | 현재 실행 완료 후 곧바로 새 명령 이어서 실행 |
| 사진 촬영 중에 타이머가 울려야 할 때 | 촬영을 끝낸 직후에 타이머 알림 표시 |

---

## 9. 참고

- 공식 발화 외 다른 표현은 **인식하지 않습니다**. 예: "에어컨 켜" / "에어컨 틀어줘" 는 실패.
- 영어 명령(예: "turn on the light")은 더 이상 지원하지 않습니다.
- 발화 시작 시 들리는 짧은 효과음은 RIO가 듣기 시작했다는 신호입니다. 이 소리가 들리고 나서 말해도 되고, 동시에 말해도 VAD가 잡습니다.
